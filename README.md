# Project-3-Ecommerce-Analytics
# E-commerce Analytics Dashboard

## Project Overview

In this project, we analyzed customer and product performance along with sales and profit performance. We also used statistical analysis and forecasting to understand future business performance.

## Tools Used

* Python
* Jupyter Notebook
* Power BI

## Key KPIs

* Total Revenue: 5,865,293.05
* Total Profit: 970,019.41
* Total Orders: 34,500
* Total Customers: 7,903
* Average Order Value: 170.01
* Profit Margin: 16.54%

## Analysis

The project includes analysis of:

* Customer performance
* Product and category performance
* Sales performance
* Profit performance
* Regional performance
* Payment methods
* Customer returns
* Delivery time
* Statistical analysis
* Future sales and profit forecasting

## Statistical Analysis

Statistical analysis was used to understand the relationship between different business variables and profit margin.

Revenue prediction achieved an R² value of 0.7627, while profit margin prediction achieved an R² value of 0.6426.

## Forecasting

Future revenue and profit were forecasted for the next three months using historical sales data.

The forecast helps to understand possible future business performance and supports better business planning.

## Dashboard

The Power BI dashboard includes:

* Business overview
* Customer and product analysis
* Statistical analysis
* Future revenue and profit forecasting

The dashboard can be filtered using Month, Category, and Region.



## Project Files

* `ecommerce_sales_analysis.ipynb` - Python analysis and statistical analysis
* `ecommerce_sales_34500.csv` - Dataset
* `dashboard.png` - Power BI dashboard screenshot
* `final_forecast.csv` - Forecast results

## Objective

The main objective of this project was to analyze e-commerce data, understand customer, product, sales and profit performance, and use statistical analysis and forecasting to gain future business insights.
